What's in the skeleton?

Every ghost-run app is a recipe with two ingredients.

Your world

You write six functions.

  • snapshotcopy reality
  • steptry one action on the copy
  • diffwhat changed
  • renderdraw it for the screens
  • fingerprintprove reality stayed the same
  • effectsOutsidewhat would leave the box

🎃 That's all. Ghost Cloud's whole world is about 800 lines.

Make your own costume

      
Write six functions, or let a Kiro agent write them with you.

      

        

          
📖 The spell: a world in six functions


const myWorld: World<MyState, MyAction> = {
  snapshot,       // copy reality, never touch it
  step,           // try one action on the copy
  diff,           // what changed
  render,         // a scene for the skeleton's screens
  fingerprint,    // prove reality stayed the same
  effectsOutside, // what would leave the box
};

        

        

          
Ask world-smith

          
A Kiro custom agent. It copies the spec template, writes the world with you one file at a time, and runs the registration gate and the wards.

          kiro-cli chat --agent world-smith
